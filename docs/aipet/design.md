# 设计稿

下图展示了AIPet的最新版本设计稿，更新日期与本页更新日期相同。

你也可以前往ExcaliDraw查看[交互式设计稿](https://excalidraw.com/#json=D9JiTmdyS1TgPdqZ0dJQx,lwrRNfmrO-ZQa-RyBuAmog)。

:::note[为什么是英文的？]
为了方面Seatide后续的国际化发展，后续的开发工作将以英文进行，这包括相关项目的Wiki、提交信息、README、Issue语言、代码注释语言等。中文将作为可选择翻译的第二语言，但不是首要编写语言。

如果你确实需要一个中文版本，可寻求支持多模态（图像识别）的AI的帮助，或在Seatide讨论群中反馈。
:::
